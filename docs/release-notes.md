Desktop installers for open-quake, the open-source DecoKee QUAKE controller.

Choose your operating system and architecture from the attached downloads. macOS supports Apple Silicon. Windows and Linux offer x64 and ARM64 builds. Tagged macOS downloads require Developer ID Application signing and Apple notarization. Windows downloads aren't Authenticode signed, so SmartScreen may show an unknown-publisher warning.

See [installation instructions](https://github.com/ramarivera/open-quake/blob/HEAD/docs/releases.md) for installation, Linux HID access and platform limitations. Hardware and planned-feature acceptance are separate from installer startup checks. There's no automatic updater yet.

Verify downloads against SHA256SUMS.txt. GitHub build provenance can also be checked with `gh attestation verify <file> --repo ramarivera/open-quake`.
