# Design

## Scope
Execution is authorized for input, click feedback, visible names, tests and diagnostics. The three proposals are complete. Ramiro selected the Instrument Console home and editor with the Scene Rail profile selector and knob overlay on 2026-10-29. Existing HID/protocol/storage identifiers stay compatible.

## Fixed comparison scenes
All three Opus5.5 CLIProxyAPI workers use identical scenes: device home1920x480 with clock, output volume, Agent command input and scene/actions; device knob/profile selector1920x480 with current selection, previous/next choices and explicit selection behavior; management studio key editor at1280x900 with selected device/profile, key grid and action inspector. Same representative content across directions. Each direction changes information architecture, hierarchy and interaction presentation, not only colors.

## Input and observation
Trace actual mounted DOM/vendor input to the canonical coordinate transform. Test all supported orientations and scaled roots, releases/cancellation, overlay routing and duplicate suppression. Remove diagnostic-looking click markers from ordinary device presentation while retaining intentional pressed/selected feedback. Log bounded identities and routing decisions through existing Effect/Pino privacy projection; never credentials, prompts, serials or raw frames.

## Completion
The selected hybrid is implemented and shown in the actual renderer; changes are committed/pushed with focused device-first and management regressions. One review addressing round per PR. Actual touch/knob physical behavior remains explicitly unverified until observed.

## Selected hybrid implementation
Instrument Console uses dark connected banks, amber selection and large numeric hierarchy for device tiles, with a strip mirror, key table and working inspector in Management Studio. Scene Rail uses a dimmed home, an instruction column and previous/selected/next profile cards with slate and jade styling. Selected and active profiles remain distinct. The knob overlay uses the same destination hierarchy without a decorative spinning ring.

Preserve arbitrary saved key placements, profile identifiers, editor actions and storage contracts. Do not replace user content with prototype values or migrate layouts merely to match sample content. An explicit Create console profile action imports and selects a new seven-tile preset through existing contracts, retaining every previous profile. Its four Agent actions use the shipped route mappings rather than invented Focus/Meeting/Studio behavior. Clock and Agent input opt into saved spans only with the explicit Console compatibility layout marker. Unmarked keys, including bundled clocks saved as one cell, retain their legacy forced spans. Creating the preset activates it through the profile manager before selecting its page in the editor. Apply the console presentation to real tile types, clock, live volume and Agent controls; existing profile contents remain the source of truth. Selector geometry and physical touch hit testing share one layout. Handle empty, one, two and many profiles, overflow names, keyboard access and reduced motion. Keep locale-aware labels and privacy-safe diagnostics.
