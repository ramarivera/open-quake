# Design

## Scope
Execution is authorized for input, click feedback, visible names, tests and diagnostics. Redesign work produces comparable proposals, not a silently selected implementation. Existing HID/protocol/storage identifiers stay compatible.

## Fixed comparison scenes
All three Opus5.5 CLIProxyAPI workers use identical scenes: device home1920x480 with clock, output volume, Agent command input and scene/actions; device knob/profile selector1920x480 with current selection, previous/next choices and explicit selection behavior; management studio key editor at1280x900 with selected device/profile, key grid and action inspector. Same representative content across directions. Each direction changes information architecture, hierarchy and interaction presentation, not only colors.

## Input and observation
Trace actual mounted DOM/vendor input to the canonical coordinate transform. Test all supported orientations and scaled roots, releases/cancellation, overlay routing and duplicate suppression. Remove diagnostic-looking click markers from ordinary device presentation while retaining intentional pressed/selected feedback. Log bounded identities and routing decisions through existing Effect/Pino privacy projection; never credentials, prompts, serials or raw frames.

## Completion
Three viewable proposals are presented for human choice; correctness changes are committed/pushed with focused device-first and management regressions. One review addressing round per PR. Actual touch/knob physical behavior remains explicitly unverified until observed.
