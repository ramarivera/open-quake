# Design

Use Effect 3.22.1 already pinned here. Speech HTTP uses fetch behind an injected port; header-authenticated WebSockets use a host port because the built-in browser WebSocket cannot attach authorization headers. No new SDK is needed. AiProviderService exposes independent speech profile operations. Speech services own credentials and revocation, abort signals, bounded decoding, 30-second synthesis and per-output leases. A player port returns natural drain independently of provider completion and must stop on release. No desktop renderer is changed.

Profiles optionally carry a provider quirk ID, per-role models and thinking/search controls. Missing roles retain the legacy daily model only for daily chat; other stages require explicit selection. Provider options are prepared before dispatch to the existing adapter port. OpenAI rejects incompatible sampling rather than dropping it. Kimi forced sampling is explicit and mismatches fail. DeepSeek rejects images. Unknown combinations fail before credential resolution.

Auto uses the routing role through the same facade, with 2048 output tokens, a 300-second deadline and strict JSON Schema decoding. Recovered six categories map to existing explicit modes; agents, shortcuts and meetings are approved routing extensions, never inferred executable code. Home Assistant is included only when enabled. An injected dispatch port resolves each target in its owning lane. Follow-up state is caller-owned and returned as a route, avoiding global session leakage. Explicit key modes bypass classification. No automatic retry or plain-text-as-command fallback.
